# PVB Beoordelingsformulieren

Deze pdf-bestanden zijn DEMO beoordelingsformulieren voor de PVB (Proeve van Bekwaamheid) van het Expert IT - System Engineer team. Ze worden gebruikt om de prestaties en waarde van teamleden te evalueren op basis van verschillende criteria.

Om de student daadwerkelijk te beoordelen, zal de praktijkopleider digitale beoordelingsformulieren toegestuurd krijgen via de mail. Deze digitale formulieren zijn de officiële beoordelingsformulieren die gebruikt moeten worden voor de beoordeling van de student.

# Expert IT - System Engineer

Informatie over de stage (BPV) en de proeve van bekwaamheid voor de opleiding Expert IT - System Engineer bij Nova College Haarlem.

## Kerntaken en werkprocessen

Volgens het kwalificatiedossier ICT support and systems, kwalificatie ICT system engineer (crebo 27016), geldig vanaf 1 augustus 2025. Dit dossier vervangt Expert IT systems and devices (crebo 25606).

### Basisdeel

#### B1-K1: Ondersteunt gebruikers/hulpvragers/opdrachtgevers

| Code | Werkproces |
|---|---|
| B1-K1-W1 | Handelt meldingen af |
| B1-K1-W2 | Instrueert gebruikers |
| B1-K1-W3 | Installeert, configureert en beheert gebruikersdevices |

#### B1-K2: Installeert en beheert de infrastructuur

| Code | Werkproces |
|---|---|
| B1-K2-W1 | Installeert en configureert netwerk- en infrastructuuronderdelen |
| B1-K2-W2 | Beheert en monitort netwerk- en infrastructuuronderdelen |

#### B1-K3: Beheert applicaties

| Code | Werkproces |
|---|---|
| B1-K3-W1 | Adviseert over en configureert applicaties |
| B1-K3-W2 | Onderhoudt applicaties |

### Profieldeel ICT system engineer

#### P2-K1: Ontwikkelt digitale informatievoorzieningen

| Code | Werkproces |
|---|---|
| P2-K1-W1 | Ontwerpt en beheert een informatievoorziening |
| P2-K1-W2 | Automatiseert processen |
| P2-K1-W3 | Beheert databases |

#### P2-K2: Controleert de security

| Code | Werkproces |
|---|---|
| P2-K2-W1 | Geeft security-advies en verbetert de security |
| P2-K2-W2 | Reageert op security-incidenten |

## Inhoud

Nog geen materiaal toegevoegd.

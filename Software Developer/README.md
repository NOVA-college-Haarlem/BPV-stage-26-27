# Proeve-van-Bekwaamheid-2026

In deze repo vind je informatie over de stage en de proeve van bekwaamheid voor de opleiding Software Developer op MBO-4 bij Nova College Haarlem.

In de repo vin je ook voorbeeld beoordelingsformulieren voor de Proeve van Bekwaamheid voor het Kerntaakexamen voor Software Developer op MBO-4.

Deze formulierne dienen ter indicatie voor de beoordeling van de proef van bekwaamheid.
Deze formulieren zijn niet bindend en kunnen worden aangepast aan de behoeften van de school.
